## P0：操作正確性與信任

- **暫存語意**：原生 NES 目前是最近 16 次完整記憶體快照，不是永久 16 個槽（也不是每 16 幀過期）。反覆覆寫同一槽會淘汰其他舊快照，前端可能到讀取失敗才知過期。所有入口共用訊息。證據：[核心](../nes-wasm/src/emulator.rs)、[前端](../src/main.ts)。
- **讀檔中文**：硬體已完整恢復，但文字觀察證據重設，既有對話可能變回日文。不用截圖猜字；加換 ROM／重設／重複讀檔回歸。
- **可攜式存檔**：目前刻意拒絕舊不完整資料。需版本、ROM／核心識別、全部 mapper／APU／DMA 狀態、長度限制、原子驗證、升級策略與跨重啟測試；不能只把 in-memory token 下載成檔。

## P1：先量測，再降低中文顯示成本

**基準方法**：同 ROM／輸入重播、相同縮放與裝置，中文關／開比較。記錄核心 step、overlay、menu matching 的 p50/p95、長任務、配置量、WASM memory 增長、音訊 underrun。至少桌機與一台實機手機，排除背景分頁 rAF 停滯與 HMR 干擾。60Hz 幀預算約 16.67ms，但要報各階段耗時，不只平均 FPS。

**候選優化**（依量測決定）：

| 位置 | 候選 | 限制 |
| --- | --- | --- |
| [圖層](../src/game-profiles/text-overlay.ts) | 每次合成建 framebuffer 副本、可能另建 sprite buffer／ImageData、重建 Map／Set；可重用固定 buffer、快取字寬、預編譯 menu pattern | — |
| Canvas 上傳 | 無遮罩／無中文時跳過額外合成 | 有中文時仍保持原生像素遮罩與 winning sprite 順序 |
| dirty cache | 字未變時減少重算 | palette、CHR、世代、sprite、捲動都會改變安全位置；key 必須含來源證據，**不能跳過驗證** |
| `measureText()` | 量測／快取重複 shaping | 不能斷定造成 DOM layout thrashing；也不是每幀處理全部 2,199 筆譯文 |
| WASM view | — | memory 增長會使 view 失效；重取 buffer 是正確性保護，共用只能在所有可能配置的呼叫之後建立 |
| [卡帶](../nes-wasm/src/cartridge.rs) | 深複製含 ROM vector，16 次快照增加記憶體；先量 peak，再考慮共用不可變 ROM／只複製可變狀態 | 不得共享 mutable mapper／RAM |

**驗收**：同輸入的硬體／原 framebuffer 與既有安全遮罩測試不退步，再比 p95、配置量與音訊；不以「感覺順」過關。

## P1：版面與輸入體驗

- 統一 MENU、鍵盤、觸控的暫停／存讀檔／返回行為與提示；重載、離開將失去暫存等危險動作要清楚提醒。
- 可關閉的按鍵說明、手把對應、焦點／鍵盤導覽；遊戲方向選單規則不要誤當按鍵無效。
- 手機固定驗收矩陣：橫直向、safe area、瀏覽器列收合、虛擬按鈕多點觸控、contain letterbox；方向盤與 A/B 可同按、不捲頁、選單不遮必要資訊。
- 維持既有視覺設計，先修狀態回饋、可讀性與觸控可達性。

## P2：CI 與發佈

- CI 分兩層：無 ROM 的公開單元測試／build；本機持有 ROM 的 opt-in 整合測試。不新增 ROM，版本化來源定義與可重建工具。
- 現有 [Pages 工作流程](../.github/workflows/deploy.yml) 在 main push 後建置／部署，沒有獨立測試關卡；push 成功不等於部署成功。
- 儲存庫本來已追蹤 ROM，授權與公開發佈清理需另外盤點，不能宣稱為無 ROM 儲存庫。
- 譯文三方合併與正式發佈驗證，避免舊本機草稿遮蔽新版縮句；固定字型若要打包先核對授權。
